Integration probes used against an isolated Leaf 1.21.11-179 server with ElytrixBotsTrain installed and `online-mode=false` bound to loopback. `Probe.java` is a **test-only plugin**; it changes blocks near 0,100,0, teleports TestOwner, and sets its bot options, so do not install it on a real server. Build it against the unpacked Leaf libraries with `paperweight-mappings-namespace: mojang` in the manifest and a plugin.yml declaring dependency on ElytrixBotsTrain. It logs follow position, yaw and attack damage. `test-ai.js` and `test-menu.js` require the `minecraft-protocol` npm package, connect to port 25571 and run for 16/14 seconds. The menu probe toggles settings on OtherGuy. These checks are not a substitute for a graphical client, obstacle/pathfinding, ViaVersion, or production-plugin tests.

`CombatProbe.java` (class Probe; compile as Probe.java) is an additional destructive isolated-server probe requiring GreatCombat. It exercises direct CombatManager start calls and an existing tag, then cycles through presets and logs bot damage and falling state. The test copy of GreatCombat was changed only to remove its Maven library declaration because the sandbox could not reach Maven; Leaf's bundled Caffeine was used. Integrations needing PlaceholderAPI, Essentials and WorldGuard were disabled in the isolated test config. This does not reproduce the production stack or a full player-versus-player fight.
