# ElytrixTalisman TEST1

Патч к оригинальному JAR SHA256 `bd3220a91d8381b4e221766d1e86078865d2da7e50cdc329cfb9ab0006cb69fa`; исходников оригинала нет. `build.sh /абсолютный/путь/к/original.jar` создаёт артефакт и запускает тесты. Требуются Java 21, ECJ, ASM (core/tree/analysis) и JOML; пути задаются переменными JAVA, ECJ, ASM, JOML (для теста анализа также нужен путь, указанный в скрипте). Заглушки только для тестирования, в JAR не упакованы.

- TextDisplay 1.19.4+: верхняя строка розовая и увеличена, остальной текст сохраняет шаблон и плейсхолдеры, фон прозрачный, тень включена. Две строки-дисплея восстанавливаются вместе при частичной пропаже. Очистка старых помеченных ArmorStand ограничена загруженными чанками и радиусом.
- Новые WorldGuard ID имеют собственный префикс `elytrix_talisman_`. Автоматическое удаление старых ID `elytrix_` прекращено: определить владельца нельзя. Удаляйте старые остатки только после ручной проверки.
- Запуск блокируется при незавершённом откате и при наличии pending-файлов. Схематика не вставляется без записи резервной копии. Неуспешные откаты сохраняют её; при неудаче вставки вызывается откат. Проверяется, что отдельный блок талисмана внутри снимка. При ошибке проверьте консоль, сделайте копию `plugins/ElytrixTalisman/restore` и восстановите мир до удаления этих файлов. Проверка не делает файловую систему crash-proof и не гарантирует целостность при повреждении диска.
- Нижняя и верхняя границы WG-региона учитывают высоту мира; поиск поверхности начинается с верхней границы. Смерти и убийства вне зоны не изменяют очки. Опасные нулевые значения таймера и очков за дроп нормализуются.
- Есть ограничения: старый плагин может сообщать об успешном `/elytrixtalisman start`, даже если запуск отклонён (смотреть консоль); консольные команды могут выбрасывать исключение. Некорректное расписание может сорвать включение; синхронный поиск до 500 случайных точек может давать лаги; нужно проверить награды и выдачу лута в реальном окружении. При `remove-schematic-on-end: false` новая защита намеренно блокирует последующие запуски, пока предыдущий снимок не восстановлен/разобран администратором.
