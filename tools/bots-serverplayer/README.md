# ElytrixBotsTrain — ServerPlayer test

Test target: Leaf 1.21.11 build 179, Java 21. `/bots` opens the create/remove menu. One server-side player per owner; the entity is hidden by default and shown only to the owner, and removed from the owner's TAB. It is not registered in the global online player list, but it exists in the world and may still be observed by server plugins, mobs or other effects. It does not attack or move intentionally. Non-owner/environment damage and entity interaction are cancelled. WorldGuard, PvP restrictions and other plugins can still cancel an owner's hit. Health is restored every tick; lethal damage is capped to protect it, so unusual very high damage is not vanilla.

The fake connection consumes outgoing packets. Because normal player knockback is applied client-side, the fake listener replays the server-computed velocity at its next tick. This is a test approximation, not a full Minecraft client. The bot's persistent data has `elytrixbotstrain:training_bot` (byte 1) and `elytrixbotstrain:owner` (UUID string), allowing future integrations to identify it. Do not globally bypass an anti-cheat; check the particular anti-cheat's APIs and account for its timing.

Build from the patched/running Leaf server directory: `JAVA=/path/to/java ECJ=/path/to/ecj.jar ./tools/bots-serverplayer/build.sh /path/to/leaf-runtime` (expects `versions/1.21.11/leaf-1.21.11.jar` and `libraries/`). Do not bundle server classes. Only Mojang-mapped 1.21.11 runtime is supported. No VirtualEntityApi dependency.

Local integration: exact supplied Leaf 179, offline-mode, Java 21, test helper and two synthetic clients. Confirmed owner-only tracking, damage via client attack packet, normal health recovery, server-calculated knockback, and a critical hit through server attack code. No visual Minecraft-client test, multi-version ViaVersion test, or test with the production plugins/anti-cheat was performed. Entity damage/particles/sounds may still be visible/audible to bystanders; packet-level isolation and compatibility need separate testing.
