# ElytrixBotsTrain

Тест для Leaf/Paper 1.21.11, Java 21. Зависимости: VirtualEntityApi и его зависимости (BLib, WorldEdit, PlaceholderAPI). ProtocolLib не требуется: используется Paper PlayerUseUnknownEntityEvent.

Команда /bots открывает меню. Один бот виден только создавшему его игроку. Удаляется при выходе, смене мира, выключении плагина или падении в пустоту. Бот — пакетный игрок, а не Bukkit Player: удары и физика имитируются. Урон, Bukkit damage events, зачарования, стрелы, точная физика блоков и античит не реализованы. Коллизия блоков упрощена до целых блоков. Проверять на ровной площадке. Окончательная совместимость с конкретной сборкой Leaf и другими плагинами требует теста на сервере.

Собранный JAR содержит только классы плагина и plugin.yml; зависимости отдельно. Исходник в src.
